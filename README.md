# Lynceus

A private, offline code-review lens that runs entirely in the browser. Paste or upload someone else's Python or JavaScript, run its tests on your own device, and get an evidence-based, prioritized review. No code ever leaves the device.

- `app/`: the app (Svelte 5 + TypeScript + Vite). See `app/README.md`.
- `spike/`: Phase 0 feasibility spike (throwaway proof code).
- `docs/`: phase reports and logs.

Brief: *Lynceus Build Prompt v2* (2026-11-21). Hosting target: `lynceus.scottchristensen.dev` (GitHub Pages).
